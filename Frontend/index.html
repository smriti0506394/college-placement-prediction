About College Placement Predictor

The College Placement Predictor is an academic web application designed to connect directly with a trained Machine Learning model.

Model Specifications:

  • Algorithm: Logistic Regression Classifier
  • Input Dimensions: Exactly 22 features (academics, coding, projects, extracurriculars, soft skills)
  • Artifacts: placement_model.pkl and placement_scaler.pkl
  • Backend: Flask API running at http://127.0.0.1:5000/predict

Strict Decoupling:

This frontend does not perform any local ML inference or hard-coded estimations. All predictions are requested via asynchronous HTTP POST directly to your Flask server.
